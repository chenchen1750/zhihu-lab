# S-01｜AI 不是学会就行，是要嵌进工作流

优先级：**最高，先打这个**

## 核心论点

绝大多数人卡在「学 AI」。真正的分水岭是把 AI 变成工作流里的一个**固定环节** —— 有触发条件、有输出格式、有人能审核、判错了能改规则。

对应 `../km-harness` 的 P-0069：先建结构，再持续维护。

## 自有案例

- 266 张书籍照片 → 结构化知识库：12 agent 并行转录 + 9 agent 逐页校对 + 全局扫描，三层质量流程
- 把 claude code 接进 IM，webhook 触发 + 定时任务，让 agent 跑日常统计
- 变更异常检查：一个 AI 取数、另一个 AI 判定并给理由，人看数据和推理链而不是结论
