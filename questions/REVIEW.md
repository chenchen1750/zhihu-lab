# 选题评审

问题从 `inbox/` 进 `active/` 之前过一遍。只要结论和一句理由，不打分。

## 五条判断

按顺序问，任何一条是「否」就先别进 active。

1. **有没有独家素材？** 这题能不能用上 km-harness 里至少 2 条条目，或一段你自己的真实职场经历？
   只能靠通用道理答的，别答 —— 那是所有人都能写的，写了也沉底。
2. **有没有一句反常识的判断？** `angle` 字段能不能写出一句和高赞答案不一样的话？
   写不出来就说明你对这题没有独特看法。
3. **脱敏之后还剩多少？** 把内部数据、公司信息全删掉，论点还站得住吗？站不住就放弃。
4. **问题还活着吗？** 关注数和最近回答时间看一眼。多年无人问津的老问题，写了没人看。
5. **和已 active 的题重不重？** 同一系列里角度高度重合的，二选一，另一个 drop 并在 `reason` 里写「与 Q-xxxx 重复」。

## 常见判断

- 问题很热但你没素材：留在 inbox，写清「缺什么素材」，等 km-harness 长出对应条目再说。
- 问题很冷但素材极强：可以写，但当成母文的草稿，发专栏而不是抢回答。
- 一个系列里有 3 个以上高度相似的问题：只 active 一个，其余标 `P2` 留作以后复用改写。
- 专栏文章（zhuanlan）不能答，别登记成问题，放进「竞品观察」。
